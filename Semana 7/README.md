## Datos

La carpeta `data/` no está incluida directamente debido al tamaño de los archivos.

Los datos del curso deben descargarse desde la siguiente carpeta de Dropbox:

[Descargar carpeta `data/` desde Dropbox]()

Una vez descargados los archivos, asegúrese de que la estructura del repositorio sea:

```text
Semana\ 7/
│
├── data/
│   ├── ...
│   └── ...
│
├── ...
└── README.md
```

Es importante que la carpeta se llame exactamente:

```text
data
```

y que se encuentre en la raíz del repositorio.

## Actualizar el repositorio

Para descargar cambios realizados posteriormente en el repositorio:

```bash
git pull
```

Antes de ejecutar este comando, asegúrese de estar ubicado dentro de la carpeta `DL_2026_02`.
